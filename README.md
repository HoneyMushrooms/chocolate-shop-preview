# Chocolate shop preview

Демонстрационная главная страница магазина «Тихое какао» в шоколадном оформлении.

Это статический макет, а не действующий интернет-магазин. Цены и ассортимент условные, изображения созданы ИИ. Кнопки показывают демонстрационные состояния. Заказы и платежи не обрабатываются. OpenCart, настройки сервера и учетные данные в репозиторий не входят.

## Публикация

В настройках репозитория открыть Settings → Pages. Выбрать Deploy from a branch, ветку main, папку / (root), затем сохранить. Входная страница — index.html. Файл .nojekyll отключает обработку Jekyll. Отдельная сборка не требуется.

## Локальный просмотр

Открыть index.html в браузере. CSS, JavaScript и изображения находятся рядом; внешние сервисы для просмотра не нужны.

## Структура верстки

Вся разметка находится непосредственно в index.html: шапка, секции, карточки, иконки, подвал и диалог. Страница отображается без JavaScript. app.js содержит только обработчики меню, выбора размера и демонстрационных действий; он не генерирует HTML. При интеграции разметку можно перенести в Twig-шаблоны OpenCart, заменив статические карточки данными каталога и демонстрационные действия реальными.

## Обновление

Исходник выбранного дизайна в рабочем проекте: concept/home-designs/dark.html. При переносе обновлений сохранять имя index.html и не добавлять ссылки на неопубликованные варианты. В публичном макете оставлена маркировка демонстрации и запрет индексации поисковиками.
